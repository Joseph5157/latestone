# IBM Plex Sans

Unmodified Regular (400) and SemiBold (600) WOFF2 fonts from IBM's official
[Plex repository](https://github.com/IBM/plex), pinned to commit
`bf260093582f04622aacc1e9f9ca604d7ccd0c42`.

Upstream directory: `packages/plex-sans/fonts/complete/woff2/`.
The accompanying `LICENSE.txt` is from `packages/plex-sans/LICENSE.txt` at the
same commit (SIL Open Font License 1.1).

Served locally by Dash; used only by the Fleet Condition Summary and Fresh
Data Coverage cards. No remote font request or JavaScript dependency is needed.
