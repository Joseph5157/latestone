# CC-10 Shortcuts

## Purpose
Give fast access to existing operational workspaces.

## Candidate destinations
- Asset Explorer / asset navigation surface
- Needs Attention anchor/filtered surface if real
- Transformer workspace
- Operations / Device Management
- Reports
- Notifications

## Rule
Only show a shortcut when its destination is a real route/capability and is authorized for the signed-in role. Do not create a dead shortcut merely to match the mockup.
